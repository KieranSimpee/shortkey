You’re on localhost

Phones cannot reach localhost. On the same Wi‑Fi, open Beauty on your PC (npm run dev → :3005), then on the phone use:

http://<your-PC-LAN-IP>:3005/desk/#family

Find LAN IP on Windows: ipconfig → IPv4. Chrome Android often allows LAN HTTP; iOS Safari usually wants HTTPS for a reliable home-screen app — prefer the deployed URL below for iPhone.

iPhone (Safari)

  1. Open the URL in Safari (not Chrome-only).
  2. Tap Share → Add to Home Screen.
  3. Name: Minion Desk → Add. Open the icon → unlock with soft PIN → Family.

Android (Chrome)

  1. Open the URL in Chrome.
  2. Menu ⋮ → Install app or Add to Home screen.
  3. Open the icon → unlock → Family / Minion Chat.
