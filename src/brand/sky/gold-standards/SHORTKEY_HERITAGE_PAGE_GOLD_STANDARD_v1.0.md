# SHORTKEY HERITAGE PAGE GOLD STANDARD v1.0  ## Official Shortkey Design Language - Heritage Page Specification  ---  ### PURPOSE  This document defines the exact visual standard for all Shortkey heritage pages. All future builders MUST follow these specifications to maintain cultural authenticity and editorial quality.  ---  ### LAYOUT SPECIFICATIONS  #### Grid System  - **Primary Grid**: 12-column responsive grid  - **Content Split**: 60% text content, 40% visual timeline  - **Mobile Adaptation**: Single-column stack, timeline becomes collapsible  - **Section Padding**: 80px top/bottom, 60px left/right  #### Visual Hierarchy  1. **Section Header**: 'Japanese Komenuka Heritage' (largest) 2. **Breadcrumb Navigation**: Path tracking (small) 3. **Progress Indicator**: Reading progress (top) 4. **Main Content**: Editorial text blocks (medium) 5. **Timeline Sidebar**: Historical context (medium) 6. **Interactive Elements**: Hotspots, tooltips (small)  #### Element Positioning  - **Progress Indicator**: Top center, 20px from top edge  - **Breadcrumb**: Below progress indicator, 30px spacing  - **Section Header**: Below breadcrumb, 60px spacing  - **Content Split**: Text left (60%), Timeline right (40%)  - **Navigation CTAs**: Bottom, 40px from content  ---  ### TYPOGRAPHY SYSTEM  #### Font Families  - **Section Headers**: Cormorant Garamond, 600 weight, 3rem desktop / 2.2rem mobile  - **Body Text**: Merriweather, 400 weight, 1.1rem desktop / 1rem mobile  - **Timeline Labels**: Montserrat, 500 weight, 0.9rem  - **Interactive Elements**: SF Pro / Segoe UI, 400 weight, 0.85rem  - **Navigation CTAs**: Montserrat, 600 weight, 1rem  #### Typography Colors  - **Section Headers**: Deep Green (#2D4A3E) - primary branding  - **Body Text**: Charcoal (#2C2C2C) - readability  - **Timeline Labels**: Soft Brown (#8B7355) - historical context  - **Interactive Elements**: Gold (#C9A962) - accent highlights  - **Navigation CTAs**: Deep Green (#2D4A3E) - consistent branding  #### Typography Rules  - **Line Height**: 1.3 for headers, 1.8 for body text  - **Letter Spacing**: 0.03em for headers, 0.01em for body  - **Text Transform**: None (preserve case)  - **Text Alignment**: Left for all content elements  ---  ### IMAGE STYLE SPECIFICATIONS  #### Historical Imagery  - **Style**: Documentary-style photography with archival quality  - **Treatment**: Slightly desaturated (10%), warm tone overlay  - **Composition**: Balanced, with negative space for text overlay  - **Quality**: High-resolution, vintage aesthetic with modern clarity  #### Timeline Visuals  - **Timeline Points**: Circular markers, 12px diameter  - **Active Point**: Gold (#C9A962) with glow effect  - **Inactive Points**: Soft Brown (#8B7355)  - **Connecting Lines**: Thin (2px), Soft Brown (#8B7355)  #### Cultural Pattern Elements  - **Background Patterns**: Traditional Japanese patterns at 5% opacity  - **Pattern Placement**: Behind content areas, not interfering with readability  - **Pattern Style**: Seigaiha (wave) or Asanoha (hemp leaf) patterns  ---  ### COLOR PALETTE  #### Primary Colors  - **Cream Background**: #F5F0E6 (base)  - **Deep Green**: #2D4A3E (section headers, CTAs)  - **Charcoal**: #2C2C2C (body text)  - **Soft Brown**: #8B7355 (timeline, accents)  #### Secondary Colors  - **Gold Accent**: #C9A962 (interactive elements, active states)  - **Sakura Pink**: #E8B4B8 (subtle highlights)  - **Muted Red**: #A85D5D (special callouts)  #### Color Usage Rules  - **Background**: Always cream (#F5F0E6)  - **Headers**: Always deep green (#2D4A3E)  - **Body Text**: Always charcoal (#2C2C2C)  - **Timeline Elements**: Soft brown (#8B7355) with gold (#C9A962) active states  - **Interactive Elements**: Gold (#C9A962) for hover states  ---  ### INTERACTION STYLE  #### Hover Effects  -
