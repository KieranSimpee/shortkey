# SHORTKEY INGREDIENT PAGE GOLD STANDARD v1.0  ## Official Shortkey Design Language - Ingredient Page Specification  ---  ### PURPOSE  This document defines the exact visual standard for all Shortkey ingredient spotlight pages. All future builders MUST follow these specifications to maintain educational depth and visual sophistication.  ---  ### LAYOUT SPECIFICATIONS  #### Grid System  - **Primary Grid**: 12-column responsive grid  - **Content Split**: Center molecular visualization (40%), traditional timeline (30%), modern research (30%)  - **Mobile Adaptation**: Vertical stack, molecular visualization becomes expandable  - **Section Padding**: 60px top/bottom, 40px left/right  #### Visual Hierarchy  1. **Ingredient Header**: 'Komenuka 米糠' with scientific name (largest) 2. **Molecular Visualization**: Interactive 3D model (center, large) 3. **Traditional Uses**: Timeline (left, medium) 4. **Modern Research**: Accordion sections (right, medium) 5. **Benefits Cards**: Breakdown cards (bottom, small) 6. **Interactive Elements**: Hotspots, tooltips (small)  #### Element Positioning  - **Ingredient Header**: Top center, 40px from top edge  - **Molecular Visualization**: Center, 30% from top  - **Traditional Timeline**: Left side, 20% from left edge  - **Modern Research**: Right side, 20% from right edge  - **Benefits Cards**: Bottom, 40px from molecular visualization  ---  ### TYPOGRAPHY SYSTEM  #### Font Families  - **Ingredient Name**: Playfair Display, 700 weight, 3.5rem desktop / 2.5rem mobile  - **Scientific Name**: Cormorant Garamond, 400 italic, 1.5rem desktop / 1.2rem mobile  - **Section Headers**: Montserrat, 600 weight, 1.5rem desktop / 1.3rem mobile  - **Body Text**: Merriweather, 400 weight, 1rem desktop / 0.9rem mobile  - **Interactive Labels**: SF Pro / Segoe UI, 400 weight, 0.85rem  #### Typography Colors  - **Ingredient Name**: Gold (#C9A962) - primary highlight  - **Scientific Name**: Charcoal (#2C2C2C) - academic standard  - **Section Headers**: Deep Green (#2D4A3E) - consistent branding  - **Body Text**: Charcoal (#2C2C2C) - readability  - **Interactive Labels**: Soft Brown (#8B7355) - subtle guidance  #### Typography Rules  - **Line Height**: 1.2 for ingredient name, 1.6 for body text  - **Letter Spacing**: 0.02em for headers, 0.01em for body  - **Text Transform**: None (preserve case for scientific names)  - **Text Alignment**: Center for ingredient name, left for content sections  ---  ### IMAGE STYLE SPECIFICATIONS  #### Molecular Visualization  - **Style**: Clean 3D molecular model with gold accents  - **Background**: Subtle gradient (cream to white, 10% opacity)  - **Interactivity**: Rotate/zoom capability, clickable atoms  - **Lighting**: Soft studio lighting with gold rim lighting  #### Traditional Timeline Imagery  - **Style**: Historical illustrations with modern clarity  - **Treatment**: Warm sepia tone (15%), slight paper texture overlay  - **Composition**: Vertical timeline with icon markers  - **Quality**: High-resolution, archival aesthetic  #### Scientific/Research Imagery  - **Style**: Clean laboratory photography with data overlays  - **Treatment**: Cool blue tint (5%), sharp focus  - **Composition**: Balanced with negative space for text  - **Quality**: Medical/scientific publication quality  ---  ### COLOR PALETTE  #### Primary Colors  - **Cream Background**: #F5F0E6 (base)  - **Gold Accent**: #C9A962 (molecular model, ingredient name)  - **Deep Green**: #2D4A3E (section headers, CTAs)  - **Charcoal**: #2C2C2C (body text, scientific names)  #### Secondary Colors  - **Soft Brown**: #8B7355 (timeline elements, labels)  - **Sakura Pink**: #E8B4B8 (benefit highlights)  - **Muted Blue**: #4A5D7A (scientific accents)  #### Color Usage Rules  - **Background**: Always cream (#F5F0E6)  - **Molecular Model**: Gold (#C9A962) accents on white base  - **Headers**: Always deep green (#2D4A3E)  - **Body Text**: Always charcoal (#2C2C2C)  - **Scientific Elements**: Muted blue (#4A5D7A) for data visualization  ---  ### INTERACTION STYLE  #### Hover Effects  - **Benefit Cards**: Subtle lift (5px), shadow appears  #### Click Actions  - **Molecular Atoms**: Detailed information modal with fade-in (0.3s)  - **Timeline Points**: Expandable content panel with slide-up (0.4s)  - **Accordion Sections**: Smooth expand/collapse (0.3s ease-in-out)  - **Benefit Cards**: Flip animation to reveal details (0.4s)  #### Micro-interactions  - **Scientific Tooltips**: Fade-in with slide-up (0.2s)  -
