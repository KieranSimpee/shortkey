# SHORTKEY COVER PAGE GOLD STANDARD v1.0  ## Official Shortkey Design Language - Cover Page Specification  ---  ### PURPOSE  This document defines the exact visual standard for all Shortkey cover pages. All future builders MUST follow these specifications to maintain brand consistency and luxury editorial quality.  ---  ### LAYOUT SPECIFICATIONS  #### Grid System  - **Primary Grid**: 12-column responsive grid  - **Hero Width**: 60% of viewport width for main visual  - **Content Alignment**: Center-aligned for primary messaging  - **White Space**: Minimum 15% padding on all sides  - **Mobile Adaptation**: Single-column stack with 20% vertical padding  #### Visual Hierarchy  1. **Primary Element**: 'HIDDEN GEMS' hero typography (largest) 2. **Secondary Element**: Edition tagline ('JAPAN EDITION') 3. **Tertiary Element**: Subtitle/description text 4. **Interactive Elements**: Floating particles, CTAs 5. **Navigation Elements**: Logo, menu, progress indicator  #### Element Positioning  - **Logo**: Top left, 80px from left edge, 40px from top  - **Menu**: Top right, 80px from right edge, 40px from top  - **Hero Text**: Centered vertically, 40% from top  - **Primary CTA**: Below hero text, 60px spacing  - **Secondary CTA**: Below primary CTA, 20px spacing  - **Progress Indicator**: Top center, 20px from top  ---  ### TYPOGRAPHY SYSTEM  #### Font Families  - **Hero Headlines**: Playfair Display, 700 weight, 4.5rem desktop / 3rem mobile  - **Edition Tagline**: Cormorant Garamond, 400 weight, 1.8rem desktop / 1.4rem mobile  - **Body Text**: Merriweather, 400 weight, 1.1rem desktop / 1rem mobile  - **CTA Buttons**: Montserrat, 600 weight, 1rem desktop / 0.9rem mobile  - **Navigation**: SF Pro / Segoe UI, 500 weight, 0.9rem  #### Typography Colors  - **Hero Text**: Gold (#C9A962) - primary messaging  - **Edition Tagline**: Sakura Pink (#E8B4B8) - accent  - **Body Text**: Charcoal (#2C2C2C) - readability  - **CTA Text**: White (#FFFFFF) - contrast on colored buttons  #### Typography Rules  - **Line Height**: 1.2 for headlines, 1.6 for body text  - **Letter Spacing**: 0.02em for headlines, 0.01em for body  - **Text Transform**: Uppercase for edition tagline only  - **Text Alignment**: Center for hero elements, left for navigation  ---  ### IMAGE STYLE SPECIFICATIONS  #### Hero Image Requirements  - **Aspect Ratio**: 16:9 for desktop, 4:5 for mobile  - **Style**: Editorial photography with luxury aesthetic  - **Lighting**: Soft, diffused natural lighting  - **Composition**: Rule of thirds, negative space for text overlay  - **Quality**: Minimum 3000px width, print-quality resolution  #### Visual Elements  - **Floating Particles**: Komenuka rice particles with subtle glow effect  - **Particle Animation**: Gentle floating motion, 0.5px/second drift  - **Particle Size**: 2-4px diameter, varied opacity (0.4-0.8)  - **Particle Color**: Gold (#C9A962) with white glow overlay  #### Image Treatment  - **No Filters**: Natural, unprocessed photography  - **Subtle Vignette**: 5% darkening at edges for depth  - **Color Grading**: Warm tones, slightly desaturated for elegance  ---  ### COLOR PALETTE  #### Primary Colors  - **Cream Background**: #F5F0E6 (base)  - **Gold Accent**: #C9A962 (hero text, particles)  - **Deep Green**: #2D4A3E (primary CTA, navigation)  - **Sakura Pink**: #E8B4B8 (edition tagline, accents)  #### Secondary Colors  - **Muted Red**: #A85D5D (secondary CTA)  - **Soft Brown**: #8B7355 (decorative elements)  - **Charcoal**: #2C2C2C (body text)  #### Color Usage Rules  - **Background**: Always cream (#F5F0E6)  - **Primary Actions**: Deep green (#2D4A3E)  - **Secondary Actions**: Muted red (#A85D5D)  - **Accent Elements**: Gold (#C9A962) and Sakura Pink (#E8B4B8)  - **Text**: Charcoal (#2C2C2C) for body, Gold (#C9A962) for hero  ---  ### INTERACTION STYLE  #### Hover Effects  - **Primary CTA**: Background darkens by 15%, scale 1.02, shadow appears  - **Secondary CTA**: Background darkens by 10%, scale 1.01  - **Particles**: Glow intensifies by 20%, slight enlargement  - **Navigation Elements**: Underline appears, color shift to gold  #### Click Actions  - **CTA Button**: Ripple effect (0.3s), scale down to 0.98 then return to 1.0  - **Logo Click**: Smooth fade transition (0.5s) to home  - **Menu Click**: Slide-in panel from right (0.4s ease-in-out)  #### Micro-interactions  - **Particle Hover**: Ingredient tooltip appears with fade-in (0.2s)  - **Scroll Indicator**: Gentle bounce animation, 1s cycle  - **Progress Bar**: Smooth fill animation, 0.6s ease-out  #### Loading States  -
