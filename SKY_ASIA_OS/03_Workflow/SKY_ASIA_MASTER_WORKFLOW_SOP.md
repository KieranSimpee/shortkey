## Phase 1 — Idea Capture

| Field | Lock |
|-------|------|
| **Owner** | Kieran |
| **Purpose** | Capture vision: theme · countries · priority · go / hold intent. |
| **Input** | Founder idea · market feel · prior season lessons (if any) · mission protect. |
| **Process** | Write the idea down. Lock or flag theme. Do not invent seats or tools mid-capture. |
| **Output** | Vision note · theme candidate or theme lock · priority list. |
| **Deliverable** | Theme / idea brief ready for Sky (Level 1 → Level 2 handoff). |
| **Next Step** | → Phase 2 Sky Analysis |

---

## Phase 2 — Sky Analysis

| Field | Lock |
|-------|------|
| **Owner** | Sky（總指揮 · Manager） |
| **Purpose** | Turn Kieran’s idea into an organized plan — without producing content, design, or research. |
| **Input** | Phase 1 vision note · theme lock (or candidate) · Dashboard / Task Center state · brand hard locks. |
| **Process** | Think → Decide: what must move · what “done” looks like · what blocks · who can own what. Sky Method only. |
| **Output** | Analysis brief · owner map draft · blockers · success criteria. |
| **Deliverable** | Plan ready to assign (no freelancing into department work). |
| **Next Step** | → Phase 3 Task Distribution |

---

## Phase 3 — Task Distribution

| Field | Lock |
|-------|------|
| **Owner** | Sky |
| **Purpose** | Assign one clear owner per task with output and deadline. |
| **Input** | Phase 2 plan · seat map (Kura · Simpee · Maya · Senti · Cursor HQ). |
| **Process** | ASSIGN only: Research → Kura · Business → Simpee · Content → Maya · Creative → Senti · Integrate → Cursor. Update Task Center. |
| **Output** | Task board with owners · outputs · deadlines. |
| **Deliverable** | Assignment pack live on Task Center / Dashboard. |
| **Next Step** | → Phase 4 Research (and parallel 5–7 as assigned) |

## One-Line Workflow

**Idea (Kieran) → Analyze (Sky) → Assign (Sky) → Research (Kura) → Business (Simpee) → Content (Maya) → Creative (Senti) → Integrate (Cursor) → Sky Review → Kieran Approve → Publish (manual) → Community (Senti+Maya) → Analytics (Sky+Simpee) → Knowledge Hub (Cursor) → Next Season (Sky) → repeat.**
