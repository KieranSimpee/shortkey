## 6. Knowledge Hub IP

Knowledge Hub is the OS **IP layer** — shared research memory that compounds across seasons.

| Asset | Where | Rule |
|-------|-------|------|
| Research notes | `00_Headquarters/knowledge/` | Short notes · dated · sourced · gated |
| Canonical index | `KNOWLEDGE_HUB/INDEX.md` | Every new note listed here |
| Structured DBs | `05_Database/` | Artists · Creators · Brands · Culture · Festivals |
| Write-back | After publish | Lessons · sources · decisions → Hub → next Sky brief |

**Note format:** Topic · Country · Why it matters for season · Sources · Status (`CURSOR_RESEARCH` / `KURA_QC` / `GOR_GOR_REVIEW` / `APPROVED`)  
**Hard rule:** No fake handles · no invented follower counts · no placeholders in shippable content.  
Publish without Knowledge Hub write-back is incomplete.

## 8. Core Principles

1. **One Blueprint.** This file is the SSOT overview; other SKY_ASIA_OS docs are detail appendices.
2. **Discovery-first.** Beauty is a lane, not the whole identity.
3. **Four levels. No freelancing.** Vision → Strategy → Departments → Cursor HQ.
4. **Sky manages; departments produce.** Think → Decide → Assign → Review.
5. **Cursor executes; Cursor does not decide DNA.**
6. **GOR_GOR_REVIEW + Kieran** before ship (approve / hold / revise).
7. **No auto-social · no public pricing · no PII in creatives · no placeholders.**
8. **No new agents / tools / MVP redesign** from cadence or docs work unless founder orders.
9. **Knowledge compounds.** Research → DB → content → publish → Hub write-back → next season.
10. **ShortKey family locks stay for ShortKey work.** SKY ASIA OS seats apply inside this OS — conflicts go to Gor Gor + Kieran (`02_Team/CONFLICTS.md`).

---

## 9. Final Goal

Run **SKY ASIA OS** as a living discovery platform: seasons that find Asia’s culture, creators, beauty, brands, and youth energy — support creators, celebrate culture, and inspire the next generation — with Cursor as HQ, Sky as manager, departments delivering, and Knowledge Hub IP compounding every cycle.

**Success looks like:** theme locked → research in Hub/DB → season pack drafted → Gor Gor + Kieran gate → manual publish → learn → next season. One shared way of working. Not thirty competing docs.
